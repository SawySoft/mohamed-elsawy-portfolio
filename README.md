# Mohamed El Sawy — Flutter Developer Portfolio

Personal portfolio website showcasing my mobile applications, architecture, and software development work.

- **Live Demo:** https://sawysoft.github.io/mohamed-elsawy-portfolio/
- **GitHub:** https://github.com/SawySoft

## Featured Projects
- **Easy Shop (`easy_shop_workspace`):** Multi-app e-commerce ecosystem (Customer App & Admin Dashboard) built with Flutter, Clean Architecture, Cubit, and Freezed.
- **El-Ammar (`elammar` & `elammar_management`):** Dual-application contracting and home-services platform built with Flutter and Firebase.
- **Mizan:** Personal finance, budget, and installments management app built with Flutter and local `sqflite` storage.
- **Easy Chat:** Real-time messaging app built with Flutter, Firebase, and Supabase.
- **Weather App:** Live weather and forecast app integrated with Weather API.

## Built With
- **Frontend / Portfolio:** HTML5, CSS3, JavaScript, Materialize, Typed.js
- **Hosting:** GitHub Pages
