About

I am Mohamed El Sawy is a Flutter and cross-platform application developer based in Giza, Egypt, operating under the SawySoft brand. Following a Flutter mobile application development diploma completed at Easy Learn Academy in October 2026, he builds responsive mobile applications, admin dashboards, and multi-platform solutions using Clean Architecture, Cubit.
